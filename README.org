* Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:

=elpaish= is a multi-channel Emacs Lisp package archive builder, server, and
management toolkit. It orchestrates automated recipe discovery, version
derivation across snapshot, stable, and staging streams, isolated preflight
quality checks, detached OpenPGP cryptographic signing, and static HTML catalog
generation. Open the primary management dashboard with ~elpaish-status~ or
dispatch commands via ~elpaish-menu~.

** ELPAish (Recommended)
:PROPERTIES:
:CUSTOM_ID: elpaish-recommended
:END:

Add the ELPAish package repository to ~package-archives~:

#+BEGIN_SRC emacs-lisp
(add-to-list 'package-archives
             '("elpaish" . "https://tychoish.github.io/elpaish/snapshot/") t)
(package-refresh-contents)
#+END_SRC

Install with =package-install=:

#+BEGIN_SRC emacs-lisp
(package-install 'elpaish)
#+END_SRC

To verify package signatures, import the ELPAish signing key into =package.el='s keyring and enable signature checking:

#+BEGIN_SRC emacs-lisp
(url-copy-file "https://tychoish.github.io/elpaish/elpaish-keyring.gpg"
               "elpaish-keyring.gpg" t)
(package-import-keyring "elpaish-keyring.gpg")
(setq package-check-signature t)
#+END_SRC

** use-package with VC
:PROPERTIES:
:CUSTOM_ID: use-package-with-vc
:END:

Requires Emacs 30+. Installs directly from Git on first load:

#+BEGIN_SRC emacs-lisp
(use-package elpaish
  :vc (:url "https://github.com/tychoish/elpaish")
  :defer t)
#+END_SRC

#+BEGIN_SRC sh

* Configuration
:PROPERTIES:
:CUSTOM_ID: configuration
:END:

Below is a complete ~use-package~ configuration setting standard options, defaults, and keybindings:

#+BEGIN_SRC emacs-lisp
(use-package elpaish
  :ensure t
  :commands (elpaish-status
             elpaish-menu
             elpaish-build-all
             elpaish-run-checks)
  :bind (("C-c t e" . elpaish-menu)
         ("C-c t s" . elpaish-status))
  :config
  ;; Custom output and publishing URLs
  (setq elpaish-output-dir (expand-file-name "public/" default-directory)) ; default: "public/"
  (setq elpaish-base-url "https://username.github.io/my-elpa/")          ; default: "https://tychoish.github.io/elpaish/"
  (setq elpaish-release-mode 'all)                                        ; default: 'all (snapshot, stable, staging)
  (setq elpaish-sign-packages t)                                          ; default: t (requires GPG)
  (setq elpaish-preview-server-port 9001)                                 ; default: 9001 (local preview port)
  (setq elpaish-recipe-local-search-dirs '("~/src/")))                    ; default: '("~/src/")
#+END_SRC

** Key Options & Customization
:PROPERTIES:
:CUSTOM_ID: key-options--customization
:END:

- *Output Directory*: [[file:docs/api.org::#elpaish-output-dir][~elpaish-output-dir~]] defines the root filesystem
  destination for generated archive artifacts, indexes, and HTML catalogs.
- *Base URL*: [[file:docs/api.org::#elpaish-base-url][~elpaish-base-url~]] specifies the canonical public URL used for web
  links and metadata.
- *Release Mode*: [[file:docs/api.org::#elpaish-release-mode][~elpaish-release-mode~]] governs which release streams are built
  (~'all~, ~'snapshot~, ~'stable~, or ~'staging~).
- *Package Signing*: [[file:docs/api.org::#elpaish-sign-packages][~elpaish-sign-packages~]] controls whether detached OpenPGP
  signatures are generated for archive files and =archive-contents=.
- *Local Search Roots*: [[file:docs/api.org::#elpaish-recipe-local-search-dirs][~elpaish-recipe-local-search-dirs~]] lists directories
  checked by [[file:docs/api.org::#elpaish-recipe-path][~elpaish-recipe-path~]] before falling back to remote Git checkouts.

* Core Workflows
:PROPERTIES:
:CUSTOM_ID: core-workflows
:END:

1. *Registering Packages*: Declare package recipes in =packages.el= with
   [[file:docs/api.org::#elpaish-register-package][~elpaish-register-package~]]. ELPAish handles single-file vs multi-file tarball
   packaging, local directory resolution via [[file:docs/api.org::#elpaish-recipe-path][~elpaish-recipe-path~]], and monorepo
   discovery with [[file:docs/api.org::#elpaish-discover-recipes][~elpaish-discover-recipes~]].
2. *Spinning Up and Hosting an Archive*: Configure headless batch runners with
   [[file:docs/api.org::#elpaish-build-all][~elpaish-build-all~]], initialize signing via [[file:docs/api.org::#elpaish-init-signing-from-env][~elpaish-init-signing-from-env~]],
   preview locally with [[file:docs/api.org::#elpaish-serve-local][~elpaish-serve-local~]], and publish to GitHub Pages using
   automated CI workflows.
3. *Testing and Updating Packages*: Execute preflight quality gates (=checkdoc=,
   =package-lint=, byte compilation, ERT) using [[file:docs/api.org::#elpaish-run-checks][~elpaish-run-checks~]], track
   commit deltas via [[file:docs/api.org::#elpaish-status][~elpaish-status~]], and automatically derive release versions
   across snapshot, stable, and staging streams.

** Developer Machine with Local Checkouts
:PROPERTIES:
:CUSTOM_ID: developer-machine-with-local-checkouts
:END:

Configure recipe discovery to search personal project directories:

#+BEGIN_SRC emacs-lisp
(use-package elpaish
  :config
  (setq elpaish-recipe-local-search-dirs '("~/src/" "~/projects/emacs/"))
  (elpaish-load-packages "~/src/my-elpa/packages.el"))
#+END_SRC

** CI Batch Runner Script
:PROPERTIES:
:CUSTOM_ID: ci-batch-runner-script
:END:

Automate headless builds in GitHub Actions workflows:

#+BEGIN_SRC emacs-lisp
  ;; scripts/build.el (require 'package) (package-initialize) (require
  'elpaish) (require 'elpaish-recipes) (require 'elpaish-website)

  (elpaish-load-packages "packages.el") (elpaish-init-signing-from-env)
  (elpaish-build-all 'all "public/")
#+END_SRC

| [[file:docs/api.org::#elpaish-discover-recipes][~elpaish-discover-recipes~]]         | Command  | Automatically scan a monorepo and register subpackages                  |

| [[file:docs/api.org::#elpaish-build-all][~elpaish-build-all~]]                | Command  | Build packages, generate indexes, and sign archive streams              |

  signing.
